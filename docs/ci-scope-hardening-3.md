# CI-SCOPE-HARDENING-3

Auditovaný fresh main: `c021caadd8b0bfd7f14efe0590d5a700ccf7f993` (12. 10. 2026).
Vetva: `fix/ci-scope-hardening-3`. Otvorený PR #772 sa týkal homepage thumbnailov; žiadna paralelná CI oprava nebola otvorená. #762 a #764 už boli merged. Hotfix nie je fáza roadmapy Services V2.

## Potvrdené príčiny

1. V `playwright-e2e.yml` sa scope zisťoval iba na pull_request. `github.event_name != 'pull_request'` pri push zapínalo install/lint/npm test; broad E2E a production smoke brali každý main push bez klasifikácie. Preto docs-only merge #764 spustil štyri nákladné joby.
2. `auto-update-automerge-prs.yml` po každom main push skúšal aktualizovať všetky stale auto-merge PR a tým mohol spustiť ďalšiu CI vlnu. Docs-only zmena nemá dôvod meniť ich head.
3. Required validačný `npm test` už robí build. Full E2E, directory E2E a search E2E robili znovu rovnaký build rovnakého checkoutu. Full E2E zároveň vykonáva všetky tri directory specs aj všetky tri public events specs, ktoré mali aj samostatný job.
4. #762 zasahoval viac domén a migráciu. Aktuálny posledný SHA má **62 súborov**, nie skorší snapshot59. Sedemnásť workflowov preto nemožno považovať za17 chybných behov. Štyri historicky branch-gated workflowy na tomto SHA preskočili svoje joby.

## Implementácia

- `scripts/ci-scope.mjs` v6: spoločná event-range klasifikácia. PR používa base/head z udalosti; push pred/po z `github.event.before` a `github.sha`, fetch-depth0. Overené commit objekty a pre push ancestor vzťah. Diff NUL-delimited pokrýva celý merge/squash/multi-commit rozsah. Nulové/neplatné SHA, chýbajúca história, divergentný force-push, prázdny diff alebo nepodporovaná udalosť → explicitný full safety fallback, nikdy docs-only. Manual/schedule → plná validácia a produkčný smoke.
- Required job names ostávajú presne `Build, lint and unit/integration tests` a `Breed CI bootstrap, all-breed regression and Playwright`. PR trigger zostáva bez top-level paths. Scope job aj validačný scope krok teraz bežia pri každej podporovanej udalosti.
- Docs-only PR aj push: CI guard/ľahké setup, bez npm ci/lint/build/npm test/E2E/production smoke. Runtime bounded push: primeraný build/lint, relevantné focused E2E a main production smoke. Served `public/*.txt` (napr. robots.txt) a executable MDX routy sa nepovažujú za docs-only. Migrácie/dependencies/shared runtime a explicitné auth/PII/resource-access moduly: full required testovanie; samostatné bezpečnostné workflows ostávajú.
- Shared visual zmena v bounded režime navyše vykoná existujúce unified hero, section hero, landing alignment a public CSS kontrakty. Nepotrebuje novú širokú testovú zostavu.
- Full/search/directory E2E preberajú `dist/` zo **same-run** úspešnej required validácie. Artifact meno obsahuje github.sha, obsah zahŕňa hidden manifests, checkout revision a SHA256 fingerprint všetkých dist súborov. Consumer kontroluje revision, existujúci deploy-artifact validator a fingerprint. Žiadny cross-PR/cross-SHA cache reuse; chýbajúci alebo poškodený artifact zlyhá viditeľne. Neúspešný npm test blokuje consumer joby, nie je obídený.
- Dedicated directory E2E sa preskočí iba pri fullCore, keď ho vykoná required broad job. Public events job v `events-fallback-images.yml` podobne odovzdá tri identické specs full E2E; artwork SSR/6 browser testov ostávajú samostatné. Manuálne public events spustenie ostáva explicitné.
- Auto-update: ľahká klasifikácia main range, docs-only update krok preskočený. Relevantné zmeny/unknown range/manual ponechajú pôvodný update-branch expected_head_sha, conflict/draft/same-repo/auto-merge ochrany a action_required approval logiku. Docs-only udalosť nepoužívame na všeobecné liečenie starších approval-gated behov; na to zostáva manual dispatch alebo ďalší relevantný push.

## Simulované pred/po

Úspešný nominálny priechod aktuálnych YAML podmienok/triggers, nie nové GitHub meranie. Nákladný job=executed npm ci/build/lint/Playwright/clean-D1 operácia. Build počíta aj build v npm test; nepočíta implicitné vnútorné buildy neznámych helperov. Skipped matrix job má podľa GitHub job-if sémantiky jeden placeholder pred expanziou. Pri skutočnom failure sa počty downstream jobov/notification zmenia. Workers Builds od Cloudflare sú mimo GitHub Actions a tento PR nemení ich deploy konfiguráciu.

## Vedome ponechané duplicity a limity

- npm ci medzi izolovanými runner jobs je nutná inštalácia, nie zdieľateľné node_modules. Setup-node cache zostáva; žiadne rizikové cross-workflow/cross-SHA node_modules alebo build cache.
- Clean D1 je opakované aj v map/security/profile workflows, pretože potrebujú vlastné lokálne databázy a konkrétne fixture/seed sekvencie. Centrálna fresh-chain migrácia a consumer DB bootstrap nie sú identické assertions. Žiadna produkčná migrácia/deploy gate/concurrency sa nemenila.
- Pri zásahu piatich systémov päť regresných oblastí ostáva. Profile/partner/auth/Notion/SEO workflows neboli vypnuté. Admin events nie sú vo full public E2E, preto ich dedicated job ponechaný aj pri širokom PR.
- Legacy hero workflows majú branch-gated full npm test/lint/build a presné preview testy; na incidentnom #762 neboli vykonané. Ich konsolidácia sa odkladá, nepredstierame aktuálnu úsporu. Pre bežné nové hero PR required bounded job teraz garantuje relevantné štyri visual kontrakty.
- Direct docs commit do zmiešaného runtime PR môže znovu spustiť aggregate PR kontroly. Nepoužívame len posledný delta commit na preskočenie starších zlyhaných/neoverených testov; bezpečný cross-head reuse potrebuje dôkaz predchádzajúcich výsledkov a rovnakej base. Hotfix odstraňuje zbytočné automatické rebase po docs-only main push, stale PR behy sa naďalej rušia concurrency. Nepridáva falošné „testy vykonané“ statusy.
- Same-run artifact transport na GitHub je **UNVERIFIED** do prvého relevantného runtime/full CI behu; staticky overená revision/fingerprint/manifest kontrola a lokálny byte-preserving copy round-trip750 existujúcich dist súborov. To nie je nový aplikačný build na aktuálnom main ani vzdialený Actions upload/download test.
- Minútové úspory po hotfixe sú odhady. Zlyhanie pôvodného npm test zostáva viditeľné. Nezmenené required job names/triggers, branch protection, schedule/manual smoke. Žiadny auto-merge.

## Validácia

`node scripts/check-ci-scope.mjs`: pôvodné scénareA–M plus14 požadovaných Hardening3 oblastí; actual YAML job/step podmienky, reálne disposable Git merge/squash/multi-push/non-ancestor/invalid/shallow scenáre, explicitné security full režimy, failed validation blokovanie, artifact/E2E ownership a manual/schedule. Bez npm install pre docs guard, iba Node built-ins.

YAML syntax všetkých52 workflows: Python PyYAML parse, bez zmeny YAML serializerom. Cielený eslint troch CI helper skriptov, `git diff --check`, docs konzistencia a required names. Produkčný kód/UI/databáza/Notion/deploy konfigurácia nezmenené; žiadne platené externé volania ani produkčné migrácie. Kompletný npm test lokálne nespustený — CI guard testuje, že ostáva vybraný pri bezpečnostne relevantnom rozsahu.
